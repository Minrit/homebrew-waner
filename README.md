# homebrew-waner

Homebrew tap for **婉儿 (Waner)** — a secure AI agent runtime with a macOS desktop app and CLI.

```sh
brew install Minrit/waner/waner
```

Installs `婉儿.app` into `/Applications` and links `waner` into `$(brew --prefix)/bin`.
Apple Silicon, macOS 13+. The cask in `Casks/waner.rb` is rendered and pushed by the
waner release pipeline on every release; do not edit it by hand.
